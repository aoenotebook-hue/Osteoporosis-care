## Before you start

- **Filenames are exact.** The app looks each exercise file up by its `id`.
  A renamed file does not error — it simply never appears.
- **Stills first, clips later.** The app is complete and useful with images
  alone, and each still doubles as its clip's poster frame, so nothing is
  wasted. No separate poster file is ever needed.
- **Start each clip from its approved still** if your tool does image-to-video.
  It fixes the style to match the app and starts the model from a pose that is
  already clinically correct.
- **AI video is a weaker bet than AI stills.** A still either has a flat back or
  it does not; ten seconds of motion has far more chances to morph a limb.
  Review clips frame by frame, and if one fails twice on the same fault, film
  it instead — `osteo-video-clip-list.md` has the camera angle for each.
- **Check every file as a clinician.** These prompts describe correct technique,
  but tools get joint angles wrong. Whatever is on screen is what a patient copies.
